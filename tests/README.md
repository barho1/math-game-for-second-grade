# חבילת הבדיקות

בדיקות אוטומטיות למשחק, מבוססות על מסמך תרחישי הבדיקה. תוצאות ההרצה והבאגים שנמצאו מתועדים
ב‑[`docs/QA-REPORT.md`](../docs/QA-REPORT.md).

## הרצה

```bash
npm install                     # http-server ו-playwright (פעם אחת)
npx playwright install chromium
npm start &                     # שרת מקומי על פורט 8123
npm test                        # כל החבילות
npm run test:logic              # רק לוגיקה — לא דורש דפדפן ולא שרת
```

המשחק עצמו אינו תלוי בשום חבילה — התלויות כאן נחוצות רק להרצת הבדיקות.

דרישות: Node 18+, ו‑Playwright עם Chromium (`npm i -D playwright && npx playwright install chromium`).

## מה יש כאן

| קובץ | מה נבדק |
|---|---|
| `logic.js` | תקינות מתמטית של כל סוגי התרגילים בכל חמש הרמות, טווחי מספרים, מסיחים, חישוב כוכבים וספי עולמות. רץ על עשרות אלפי תרגילים. |
| `ui1.js` | שדה השם (כולל XSS ותווים חריגים), בחירת דמות/צבע/כובע, מפת העולמות וספי הפתיחה, ניווט. |
| `ui2.js` | מנגנון הטעות והרמזים, כפתורי תשובה, מקלדת מספרים, מקלדת חומרה, חישוב מטבעות וכוכבים. |
| `ui3.js` | מחירי החנות, תיבת ההפתעה, 20 המדבקות, 12 המדליות וארבעת המספרים האישיים. |
| `ui4.js` | שער ההורים, מגבלות הזמן, השעון הצץ, עצירת הספירה ברקע, הסיום העדין, דוח ההתקדמות ואיפוס. |
| `ui5.js` | שישה גדלי מסך, סיבוב מסך, RTL, שמע והשתקה, הפחתת תנועה, מצב כהה, אחסון מלא, לחיצות כפולות. |
| `ui6.js` | ארבע זרימות משתמש מלאות, שמות עולמות/פריטים/רמות, זמן טעינה ויציבות. |
| `ui7.js` | מנוע ההתאמה האדפטיבית — עלייה, ירידה, גבולות. משתמש בתרגיל מוזרק עם תשובה ידועה כדי להיות דטרמיניסטי. |
| `ui8.js` | תזמון פתיחת המדליות, ההפתעות, וצעידת הדמות במסלול. |
| `ui9.js` | manifest ואייקונים, משחק אופליין, דיוק העשיריות וציר המספרים, פרטי עיצוב. |
| `ui10.js` | ה-Service Worker: רישום, מילוי המטמון, רענון ופתיחה מאפס בלי רשת, ושמירת ההתקדמות בין הפתיחות. |

`helpers.js` מכיל פונקציות עזר משותפות (פתיחת דף נקי, מענה על תרגיל, כניסה לאזור ההורים).

## הערה על דטרמיניזם

חלק מהבדיקות מזריקות תרגיל קבוע עם תשובה ידועה (`MG.Questions.generate`) כדי לבדוק התנהגות
שתלויה ברצף תשובות נכונות — אחרת אי אפשר היה לבדוק את מנוע ההתאמה בצורה אמינה.
בדיקות אחרות מנחשות תשובות עד שהן מוצאות את הנכונה, בדיוק כמו ילד שמנסה.
